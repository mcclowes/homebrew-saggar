# homebrew-saggar

Homebrew tap for [Saggar](https://github.com/mcclowes/saggar), kiln's companion terminal manager.

```bash
brew install --cask mcclowes/saggar/saggar
```

Requires macOS 26 (Tahoe) on Apple Silicon. Releases are signed and notarized; the cask is updated automatically by saggar's release workflow.
